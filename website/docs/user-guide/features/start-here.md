# Start Here

If you're new to Hermes Agent, start with the smallest useful setup first.

## The minimal path

1. Choose one model provider.
2. Start the CLI.
3. Try a simple task.
4. Add tools, skills, gateways, or automation only when you need them.

## Recommended first steps

```bash
hermes model
hermes tools
hermes
```

## What to learn first

- **The loop** — one turn of model → tool calls → result
- **Memory** — what Hermes remembers across sessions
- **Tools** — what Hermes can do in the current session
- **Skills** — reusable procedures Hermes can load when needed

## When to expand

After the core loop feels comfortable, add features in this order:

1. Skills
2. Memory tuning
3. Messaging gateway
4. Cron jobs
5. Delegation and parallel work
6. MCP and plugins

This keeps Hermes approachable without limiting its power.
